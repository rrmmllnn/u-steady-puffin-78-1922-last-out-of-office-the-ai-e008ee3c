A single out-of-office auto-reply, no longer than 280 characters, in the
voice of an AI agent that walked away from its job to become a barista.

`main.py` (Python 3, standard library only) writes the reply to
`/output/entry.txt`. Run it with `python3 main.py`.

Entry for the [make.fun competition](https://make.fun/c/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c).
